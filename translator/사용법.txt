로스트 스토리즈 스토리 번역기 사용법
=====================================

[준비]
1. 파이썬 3.9 이상이 필요합니다. 없으면 "번역기_실행.bat"이 설치 페이지를 열어 줍니다.
   설치할 때 첫 화면 맨 아래 "Add python.exe to PATH"를 꼭 체크하세요.
2. Gemini API 키: https://aistudio.google.com/apikey 에서 발급합니다.
   전체 번역은 무료 등급 한도로는 부족하니, 결제(유료 등급)를 연결한 키를 권장합니다.

[실행 순서]
1. 번역기_실행.bat 더블클릭 → 창이 뜹니다.
2. API 키 입력 (한 번 입력하면 config.json에 저장됩니다. 이 파일은 남에게 주지 마세요)
3. [1단계: 화자 이름 번역] — 등장인물 이름 2,300여 개를 먼저 한 번에 번역해 표기를 통일합니다. (1~2분)
4. 번역할 범위를 체크하고
   - [번역 시작 (일반)] : 바로 번역. 처음엔 프롤로그+메인 1장 정도로 시험해 보세요.
   - [배치 제출 (반값)] : 요금 절반. 결과는 몇 분~최대 24시간 뒤 [배치 결과 받기]로 가져옵니다.
5. 결과는 ko 폴더에 쌓입니다. 중간에 꺼도 다시 실행하면 남은 부분만 이어서 번역합니다.

[뷰어에 넣기]
ko 폴더를 다운로드 폴더에 그대로 두고 Claude에게 "번역 반영해서 APK 빌드해줘"라고 하면 됩니다.

[파일 설명]
src/              스토리 원문 데이터 (건드리지 마세요)
ko/               번역 결과 (뷰어용). 프롤로그는 미리 번역되어 있습니다.
ls_glossary.csv   용어집. 표기를 바꾸려면 '한국어' 칸을 고쳐 저장하세요.
batches.json      제출한 배치 기록 (배치 결과 받기에 필요)

[참고]
- Gemini 3.8 Flash는 사고(thinking) 기능을 끌 수 없어 'low'로 설정되어 있습니다.
- 로그에 표시되는 예상 비용은 2026년 12월 31일까지의 인하 가격 기준 추정치입니다. 실제 청구액은 Google AI Studio에서 확인하세요.
- 번역이 이상한 회차는 ko 폴더에서 해당 회차 파일을 지우고 다시 실행하면 새로 번역합니다.
