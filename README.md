# LS Story Viewer (비공개)

코드기어스 로스트 스토리즈(일본판) 스토리를 한국어로 읽는 안드로이드 뷰어와, 그 뷰어를 만드는 데 쓴 도구 모음입니다.


## 버전 기록

- v0.2.0 첫 한국어 번역판
- v0.3.0 배경·CG, 목록 제목 한글화
- v0.4.0 Live2D 캐릭터, 배경음악·효과음
- v0.4.1 카메라 이동 후 캐릭터 누락 수정, 여성 주인공, 효과음 오타 보정
- v0.4.2 분할화면(통신창), 장면별 파라미터(망토 등), 캐릭터 크기 조정
- v0.4.3 나이트메어 전투 연출 일러스트 재생 시험판 → 다음 버전에서 철회(안내 문구로 복귀). 전투 자막 번역(`translation/ko/kmf_captions_ko.json`)과 해석 도구(`tools/kmf/`)는 메모리얼 앱 대비용으로 보관
- v0.4.4 누락 캐릭터 복구: 의상 모델 7종 + 주인공 의상 인연 모델 19종×남/여
